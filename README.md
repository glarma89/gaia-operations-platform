
# Gaia Operations Platform

A full-stack application for executing configurable operations with two input parameters.

## Technology Stack

- Backend: ASP.NET Core / C#
- Frontend: React / TypeScript
- Database: Microsoft SQL Server
- Testing: xUnit

## Features

- Execute arithmetic and string operations
- REST API for external clients
- Extensible operation architecture
- Operation history and statistics (planned)
- Server-side logging (planned)

## Project Status

Initial development setup.

## Architecture

- `backend/` - .NET application
- `frontend/` - React TypeScript client
- `docs/` - Technical documentation
